\subsection{Limitations des résultats}
\label{subsec:4.6.3}

\textbf{Limitations méthodologiques} :
\begin{itemize}
\item Période de collecte limitée (X mois) vs tendances long-terme
\item Biais géographique RIPE Atlas (91\% Europe+NA)
\item Couverture limitée (Top 10K vs millions de domaines)
\end{itemize}

\textbf{Limitations techniques} :
\begin{itemize}
\item Interférence mesures RIPE Atlas (désynchronisation +/-1h possible)
\item Filtrage lying resolvers peut exclure comportements légitimes
\item Granularité temporelle quotidienne (pas horaire)
\end{itemize}

\textbf{Limitations d'interprétation} :
\begin{itemize}
\item Corrélation != causalité (TTL vs changement)
\item Providers CDN non tous identifiés
\item Effet ECS difficile à isoler complètement
\end{itemize}
